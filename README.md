# 🌟 আধুনিক ডেভেলপার পোর্টফোলিও (Developer Portfolio Blueprint)

একটি প্রিমিয়াম, আল্ট্রা-ফাস্ট এবং সাইবার ডার্ক-থিমের আধুনিক সফটওয়্যার ডেভেলপার পোর্টফোলিও ওয়েবসাইট। নিয়ন গ্লো, গ্লাস-মরফিজম, টাইপরাইটার অ্যানিমেশন, বেন্তো গ্রিড, ইন্টারেক্টিভ প্রজেক্ট কেস স্টাডি মডাল, কমান্ড প্যালেট (`Ctrl+K`), লাইভ হোয়াটসঅ্যাপ ও ইমেইল ক্লিপবোর্ড কপি সহ এটি সম্পূর্ণ প্রস্তুত।

---

## ⚡ কীভাবে সরাসরি ব্রাউজারে চালু করবেন?

কোনো সফটওয়্যার বা প্যাকেজ (`npm`) ইনস্টল করার প্রয়োজন নেই!
1. ফোল্ডারের ভেতর থাকা **`Launch_Website.bat`** ফাইলে ডাবল ক্লিক করুন।
2. অথবা **`index.html`** ফাইলটিতে ডাবল ক্লিক করুন।
3. নিমিষেই আপনার ব্রাউজারে সাইটটি ওপেন হয়ে যাবে।

---

## ✏️ কীভাবে নিজের নাম, ছবি ও তথ্য পরিবর্তন করবেন?

পুরো পোর্টফোলিওটিকে এমনভাবে তৈরি করা হয়েছে যেন **এইচটিএমএল কোড না ছুঁয়েও** আপনি সব তথ্য পরিবর্তন করতে পারেন।
শুধুমাত্র **`js/portfolio-config.js`** ফাইলটি যেকোনো টেক্সট এডিটর (যেমন: Notepad, VS Code) দিয়ে ওপেন করুন।

সেখানে পাবেন:
* **`personal.name`**: আপনার নাম লিখুন।
* **`personal.headline`**: আপনার মূল পরিচয়/ডেজিগনেশন।
* **`personal.roles`**: টাইপরাইটার অ্যানিমেশনে যে রোলগুলো ঘুরবে তার তালিকা।
* **`personal.email` ও `whatsappNumber`**: আপনার যোগাযোগ নম্বর ও ইমেইল দিন।
* **`personal.avatar`**: `assets/` ফোল্ডারে আপনার ছবি রেখে ফাইলের নাম এখানে দিন।
* **`socials`**: আপনার GitHub, LinkedIn, Facebook, YouTube লিঙ্ক বসান।
* **`skills`**: আপনার জানা প্রোগ্রামিং ভাষা ও টুলস যোগ বা বাদ দিন।
* **`projects`**: আপনার তৈরি করা প্রজেক্টের নাম, সমস্যা-সমাধানের বিবরণ, ছবি এবং লাইভ ডেমো লিঙ্ক যুক্ত করুন।

> 💡 **নোট:** শুধুমাত্র কোটেশনের (`" "`) ভেতরের লেখাটুকু পরিবর্তন করবেন, কোটেশন বা কমা বাদ দেবেন না।

---

## 🚀 কীভাবে বিনামূল্যে ইন্টারনেটে লাইভ করবেন?

### পদ্ধতি ১: Netlify Drop (সবচেয়ে সহজ — ৩০ সেকেন্ড)
1. [app.netlify.com/drop](https://app.netlify.com/drop) সাইটে যান।
2. আপনার এই পুরো `portfolio` ফোল্ডারটি মাউস দিয়ে টেনে এনে পেইজের ওপর ড্রপ করুন।
3. মুহূর্তের মধ্যেই আপনার সাইটটি লাইভ হয়ে যাবে এবং একটি ফ্রি লিংক পেয়ে যাবেন!

### পদ্ধতি ২: GitHub Pages
1. আপনার GitHub অ্যাকাউন্টে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `my-portfolio`)।
2. এই ফোল্ডারের ফাইলগুলো সেখানে পুশ বা আপলোড করুন।
3. Settings > Pages এ গিয়ে `main` ব্রাঞ্চ সিলেক্ট করে সেভ দিন।
4. ফ্রি লিংক তৈরি হয়ে যাবে (যেমন: `yourusername.github.io/my-portfolio`)।

## 📁 ফাইল স্ট্রাকচার

```
portfolio/
├── index.html               # মূল ওয়েব পেজ (SEO ও Accessible Layout)
├── Launch_Website.bat       # এক ক্লিকে ব্রাউজারে ওপেন করার শর্টকাট
├── css/
│   └── style.css            # সাইবার ডার্ক, গ্লাস-মরফিজম ও অ্যানিমেশন স্টাইল
├── js/
│   ├── portfolio-config.js  # 📌 তথ্য, প্রজেক্ট ও স্কিল পরিবর্তনের মাস্টার ফাইল
│   └── app.js               # ডায়নামিক রেন্ডারিং, মডাল, ফিল্টারিং ও কমান্ড প্যালেট
└── assets/                  # ছবি, ব্যানার ও প্রিভিউ ইমেজসমূহ
```
